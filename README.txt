MOOM 7.0 - ANA MENU, MENU SESLERI VE AYARLAR

BU SURUMDE
- MOOM kapak resmi ana menunun arka planinda kullanilir.
- 1000072123.mp4 dosyasinin ses parcasi 22050 Hz mono PCM olarak cikartilip kaynak koda gomulmustur; ana menude dongulu calar.
- 1000072121.mp4 dosyasinin ses parcasi 22050 Hz mono PCM olarak cikartilip kaynak koda gomulmustur; Oyna/Ayarlar seciminde calar.
- Ana menu: OYNA ve AYARLAR secenekleri.
- Yukari/asagi ile secim, X veya START ile onay.
- Secimden sonra kisa beyaz ekran gecisi uygulanir.
- Ayarlar ekraninda dil secimi icin Turkce/English ornegi bulunur; X ile degistirilir, O ile geri donulur.
- Onceki silahlar, silah sesleri, zombi olum sesi, ayak sesi ve levye korunmustur.

KONTROLLER
- Ana menu: Yukari/Asagi secim, X veya START onay
- Ayarlar: X dil secenegini degistir, O geri don
- Oyun: Analog/yon tuslari hareket ve donus; L1 yana yurume; R1 silah degistir; X/Kare silah kullan

DERLEME
main.c ve Makefile dosyalarini PSP SDK projenize koyup PSPSDK ile EBOOT.PBP derleyin.

DOGRULAMA
Sesler kullanicinin verdigi iki MP4 dosyasindan cikartildi. Kaynakta menu ve secim sesi kodu eklendi, ZIP icerigi kontrol edildi. Bu ortamda PSP SDK bulunmadigindan derleme ve PPSSPP testi yapilamadi; bu nedenle calisma garantisi verilemez.
